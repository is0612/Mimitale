01 — 04 / FOUR PIECES

角色卡管演谁，世界书管在哪儿
预设管怎么回，面板管记不记得住

酒馆里该有的四件事，一件都不少；每件都按能被程序接住的方式重做了一遍 —— 模型说的话，能落成数据。

01

角色卡

card

直接导入酒馆的 PNG 角色卡 —— 解析 PNG 里的 tEXt 数据块， 设定、头像、开场白、示例对话一起读进来；JSON 卡 v1 / v2 / v3 也认， 连把开场白塞进 chat_history 的变体都认。也可以从头手写一个。 示例对话会变成真正的 user / assistant 消息一起发出去 —— 扮演质量的差距就在这儿。

02

世界书

lorebook

关键词命中才注入。一本书几百条设定，只有相关的那几条进上下文 —— 四两拨千斤。条目命中后正文还能再触发别的条目，一路连锁。 副关键词、选择性逻辑、概率、常驻、扫描深度都有。 「命中预览」会拿真实对话扫一遍，先告诉你这轮要注入哪几条，再发。

03

预设

preset

叠在对话上的一层指令 —— 管的不是「演谁」「在哪儿」，而是「怎么回」： 人称、句式、篇幅密度、用词禁区、固定称呼。一场可挂多条，各自成块依次拼进提示词。 说明与正文分离：说明只给人看，正文才进提示词。也能直接吃别人分享的预设。

04

状态面板

panel

模型每轮输出的状态栏会被解析出来单独保存，下一轮由程序权威注入 —— 所以聊再多轮，数值也不会因为历史被截断而开始乱编。数值带范围，超出自动拉回； 字段能分组、能带变化规则，还能给每轮几个可点的剧情选项。 模型写 150/100，程序拉回 100/100 —— 不靠祈祷，靠代码。

05 / LONG PLAY

聊到第一百轮，它还记得开局

长对话不丢前文，靠的是三件东西叠着用 —— 不是把历史一股脑塞进上下文，那既不省也不准。

01 / SUMMARY

分段记忆摘要

较早的对话压成摘要常驻在上下文里。聊多久，开局那一幕都还在。

02 / RAG

语义检索

按「意思」把相关的旧内容和设定捞回来，不靠关键词字面命中。

03 / BRANCH

分支与存档点

走岔了能整个退回来。想看看另一条路会怎样，不用重开一局。

06 / ANY MODEL

哪家的模型都行，
一个会话用一个

DeepSeek 通义千问 Kimi 智谱 GLM 腾讯混元 MiniMax + 任何 OpenAI 兼容端点

内置 6 家国内常见平台的预设，点一下就能填好。其余平台 —— 豆包、硅基流动、千帆、阶跃、 星火、零一万物，以及境外的 —— 只要是 OpenAI 兼容端点，填个地址就能用。

每个会话记着自己用的模型：银月酒馆用 deepseek-chat、跑团记录用 qwen-max、通用助手用 glm-5.3，互不影响； 每条回答上还会标明是哪个模型答的。API Key 用系统级 safeStorage 加密后落盘。

07 / COMPANION

它不是你的化身，
是坐在旁边看你玩的小家伙。

  • 看得见你们的对话，有自己的性格，每隔几轮会插一句进来。
  • 有自己的记忆，也可以配自己的模型 —— 用便宜的那档跑就好。
  • 永不进剧情，也不写进对话记录。它只是坐在旁边看着。
「你俩又聊到后半夜了……」 它盯着屏幕，尾巴尖晃了一下
08 / NO SERVER

没有服务器，
就没有「上传」这个词

这个项目没有任何后台。主进程就是本地的 Node.js，跑在你自己的机器上。 这不是一句承诺，是它没有的东西 —— 想传也没地方传。

一般的云端 AI

你的对话 ──▶ 别人的服务器 ──▶ 回来了

聊天记录、角色设定、你写的一切，都要先在别人的机器上落一次地。

换台电脑，得重新登录；服务下线，记录跟着一起走。

子夜酒馆

你的对话 ──▶ 本机 · 直连模型 API

只有发往你自己配置的模型接口那一次请求，别的什么都不经过第三方。

数据就在程序旁边：整个 data\ 文件夹拷走，记录、角色、世界书全跟着走 —— 换机器、放 U 盘、发给别人，都不用重新配置。

页面本身被 CSP 锁死（default-src 'none'）—— 它连网络请求都发不出去。 所有系统能力都必须走进程间通信交给主进程。即使页面里被塞了恶意脚本，它也没办法把数据往外送。
09 / GET STARTED

三步，点灯开门

Terminal
# 客户端代码都在 client/ 里，先进去
cd client
# 首次会下载约 100MB 的 Electron 运行时
npm install
npm start
Electron 已就绪 —— 窗口打开了
  1. 要有 Node.js 18+ Windows / macOS / Linux 都行。Windows 用户也可以直接双击 client\Start-Mimitale.cmd，它会自己检查环境、自动装依赖，出错时给中文提示。
  2. 填一次模型接口 启动后点左下角「设置」，从内置预设里挑一家填上 API Key。只填一次， 之后每个会话自己记着用哪家、哪个模型。
  3. 把角色卡拖进来 酒馆用的 PNG 卡直接导入，设定、头像、开场白、内嵌世界书一起到位。 然后就可以开始了 —— 从今晚，或者任意一个你想回的夜晚。
