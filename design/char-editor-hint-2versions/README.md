## 二、两版的主张

**A 就地版** —— 骨架一行不动。卡底的 `<details>` 整条撤掉，头栏右侧加一枚 20px 的 `?`，点了弹出一个 344px 的浮窗：**盖在页面上、不推布局，可以按住标题栏拖走** —— 但位置**从不保存**：换字段、关掉再开、窗口缩放，都重新贴着当前那颗 `?`。关闭有三条：右上角 ×、再点同一颗 ?、Esc。**修的只有"重复"和"占位"两件事。**

**B 旁注版** —— 说明的归属改了：它不属于卡片，属于"你正在写的那一栏"。右列 264px 常驻旁注，跟着 `#char-form` 的 `focusin` 换内容（不用 IntersectionObserver，不做滚动高亮）。**顺带把行宽从 54 字/行收回到 36 字/行。**

## 三、A 版规格

### 3-1 尺寸

| 部位 | 值 | 依据 |
| --- | --- | --- |
| 右列内边距 | 上 22 / 左右 30 / 下 32 | 与现状一致，不改 |
| 卡片头栏 | 45px（padding 10/16 + 一行 24） | 与 `style.css:9814` 一致 |
| 正文最小高 | 描述 200 / 场景 84 / 开场白 128 / 示例对话 160 | 与 `style.css:6084-6089` 逐值一致 |
| `?` 按钮 | 20 × 20，圆形，`border: 1px var(--border)`，字 11px | 与头栏 24px 行高齐平，不撑高头栏 |
| 浮层 | 344 × 自适应，`top: 46px; right: 12px` | 44 = 头栏高 + 2；右侧留 12，与卡缘对齐 |
| 浮层内边距 | 14 16 15 | 与 `.note` 一致 |
| 卡间距 | 16 | 不动 |

### 3-2 状态

| 元素 | 常态 | 悬停 | 展开 |
| --- | --- | --- | --- |
| `?` 按钮 | `--border` 描边 + `--text-faint` 字 | `--border-hover` + `--text` | `--accent-border` 描边 + `--accent-soft` 底 + `--accent` 字 |
| 浮层 | — | — | `--bg-elev` 底 + 1px `--border` + `--shadow-lg` |

### 3-3 交互（这几条容易漏）

- **关法三条**：右上角 ×、再点同一颗 `?`（toggle）、`Esc`。`Esc` 只关浮窗 —— 编辑页本来也认 Esc（= 返回上一屏），所以监听挂在**捕获阶段**并 `stopPropagation`，否则会一按就退出编辑页。
- **拖拽**：整条标题栏是把手（`cursor: grab`），`pointerdown` + `setPointerCapture`，松手才夹回窗口内（拖动中可以半出界，好甩）。**位置不记**：`open()` 里无条件 `placeNear(btn)`（换字段也重贴），`close()` 再清一次 `last` —— 拖走只在这一次打开期间有效。
- **不点外部关闭**：它是个能停在旁边的小面板，点正文就消失会很难用。这是跟原稿不一样的地方（原稿写的是"点外部关闭"）。
- `aria-expanded` 跟状态同步；浮窗 `role="dialog"` + `aria-labelledby`。
- ⚠️ **按钮确实长在 `<label for="c-…">` 里面**（`.field-head` 是 `.char-sheet-label` 的子级）。所以在点击处理里 `preventDefault()` 拦掉 label 的转发动作 —— 不拦的话点 `?` 会顺带把焦点送进 textarea。冒烟里钉了这条。

## 四、B 版规格

### 4-1 尺寸

| 部位 | 值 | 依据 |
| --- | --- | --- |
| 网格 | `260px minmax(0,1fr)` → 仍是两栏，**右列内部**再切两列 | `style.css:5757` 只改一处 |
| 右列内边距 | 22 / 24 / 32 / 30（左大右小，因为旁注自己带 24 的间距） | |
| 旁注列 | **264px**，`gap: 24`，`position: sticky; top: 0` | 1440 − 224 − 260 − 54 = 902；902 − 264 − 24 = **614 稿纸** |
| 稿纸正文宽 | 614 − 32 = **582px ≈ 36 汉字/行** | 落在舒适区 22–38 的中段 |
| 旁注内边距 | 14 16 | 与 `.note` 一致 |
| 旁注标题 | 12px `--text-faint` 眉标「这一栏怎么写」+ 14px 600 字段名 | 眉标讲"这是什么"，标题讲"哪一栏" |

### 4-2 联动

```js
form.addEventListener('focusin', (e) => {
  const sheet = e.target.closest('.char-sheet');
  if (sheet) showNote(sheet.dataset.field);   // 只换旁注内容，不动 focus
});
```

- 默认显示分区里**第一张卡**的说明（进页面就有内容，不留空旁注）。
- 切分区时重置成新分区的第一张卡。
- 备选开场白那栏没有可聚焦的控件 —— 它沿用「开场白」的说明（`data-field` 指过去即可），不要为它单开一条。

### 4-3 已知代价

- 1280 宽下：1280 − 224 − 260 − 54 − 288 = **454 稿纸**，正文只剩 26 字/行，还挤。**要么设 min-width，要么 1280 以下把旁注收成折叠**（这一档本次没做，是落地时必须补的）。
- 旁注常驻 = 264px 的固定成本，即使这个字段你已经写熟了。

## 六、已知取舍（不谎报）

- 出的是**静态稿**，不是真机渲染。字体与真机一致（`Microsoft YaHei UI`），但滚动条、focus ring 这类系统绘制细节以真机为准。
- 稿子里的正文内容（小满 / 图书馆）是**示例数据**，与 `0-before.png` 的测试数据不同 —— 对比时只看结构，不看文案。
- 两版都**没动**字段含义、数据契约、导入导出、世界书绑定。
- `0-before.png` 是真机截图（`--shot=charTextareas`），内容为冒烟测试灌进去的数据。
- 素材（品牌标、头像）是项目自有。
